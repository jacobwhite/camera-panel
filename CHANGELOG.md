# Changelog

## 0.1.0

Initial public release of Camera Panel.

- Native Wayland top-edge camera panel and status notifier tray icon.
- One compact row with automatic resizing and persistent per-camera selection.
- Multiple ONVIF NVRs, LAN discovery, and manual recorder setup.
- Optional, consent-based UFW discovery permission setup.
- Low-resolution substream selection and parallel, progressive stream startup.
- Private persistent preview images and explicit ten-second connection timeouts.
- Desktop keyring credentials and optional Reolink channel-name lookup.
- Omarchy palette/font integration, portable user installer, and Arch package recipe.

This is an early release. Live playback has been tested with Reolink RLN8-410
recorders on Hyprland; other ONVIF implementations may need compatibility fixes.
